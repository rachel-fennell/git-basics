# git-basics

This repository contains exercises for learning Git and GitHub. It includes practice files, contribution guidelines, and evidence reports describing each exercise.

##Prerequisites:

Git installed
A terminal
A GitHub account for exercises that use GitHub issues, pull requests, or remote repositories

There is no application to install or build. The practice files are used with Git commands.

##Clone and inspect the repository:
git clone https://github.com/rachel-fennell/git-basics.git

##Course evidence

01 — Introduction to Git
Module 01 evidence (install and first commit; read repository history)

02 — Making Commits
Module 02 evidence (clean series of commits; rewrite poor commit messages)

03 — Branching and Merging
Module 03 evidence (branch and merge cycle; predict the merge)

04 — Remotes and GitHub
Module 04 evidence (first pull request; recover from a rejected push)

05 — Undoing Changes, Stash and Tags
Module 05 evidence (undo and recover work; tag and inspect milestones; prepare the repository)
